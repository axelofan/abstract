1Зачем нужны ДМ: номера 100 строк

📐

Способ 1. Прогрессия

Заполнить A1:A100 арифметической прогрессией от 1 до 100.

📋

Способ 2. Копирование

В A1 ввести =СТРОКА(A1), скопировать и вставить в A1:A100.

⚡

Способ 3. Динамический массив

Выделить A1:A100, ввести =СТРОКА(A1:A100) и нажать Ctrl+Shift+Enter.

Главное сочетание клавиш

Ctrl+Shift+Enter

Без этого сочетания формула посчитает только одно значение. Фигурные скобки Calc ставит сам, вручную их не вводят.

{=СТРОКА(A1:A100)}

🔒

Нельзя изменить часть массива

Отдельную ячейку диапазона-результата отредактировать нельзя.

Выделите весь диапазон массива, исправьте формулу в строке формул и снова нажмите Ctrl+Shift+Enter.

4ДМ для строк

Если на вход подать строку, результатом тоже будет строка. В строке 1 записаны числа 27, 8, 43, 50.

ABCD
12784350
2204
3ИСТИНАЛОЖЬИСТИНА
4ЛОЖЬИСТИНАИСТИНА

A2:C2 — количество десятков:

{=ЧАСТНОЕ(A1:C1;10)}

A3:C3 — какие числа больше 15:

{=A1:C1>15}

A4:C4 — меньше ли число следующего:

{=A1:C1<B1:D1}

Как сравниваются диапазоны со сдвигом

A1<B1 → 27<8 → ЛОЖЬ B1<C1 → 8<43 → ИСТИНА C1<D1 → 43<50 → ИСТИНА

6Копирование формулы с ДМ

Сначала выделите весь динамический массив!

📋

Копировать → Вставить

Скопировать массив и вставить во все ячейки итогового диапазона.

🖱️

Двойной щелчок по маркеру

Дважды щёлкнуть по маркеру в углу выделения.

🚫

Растягивание за маркер

Если тянуть массив за маркер, получится ошибка.

7Массив прямо в формуле: сортировка трёх чисел

Если значения параметра известны заранее, их можно записать прямо в формуле в фигурных скобках.

Способ 1. Вспомогательный диапазон

В D1:F1 записаны 1, 2, 3. Формула введена в G2:I2 и скопирована вниз. Знак $ закрепляет строку 1.

{=НАИМЕНЬШИЙ(A2:C2;D$1:F$1)}
ABCDEF
1123
2725257
3914149
4386368

Способ 2. Массив-константа

Строка 2 — по возрастанию, строка 3 — по убыванию.

{=НАИМЕНЬШИЙ(A1:C1;{1;2;3})}
{=НАИБОЛЬШИЙ(A1:C1;{1;2;3})}
ABC

2257

⚙️
Разделители в массиве-константе зависят от настроек: Сервис → Параметры → LibreOffice Calc → Формула. Если {1;2;3} выдаёт ошибку или даёт столбец вместо строки, проверьте там разделители столбцов и строк массива.

8Расчёт по этапам

Задачу безопаснее решать по этапам: сначала рассчитать вспомогательный массив, затем выполнить вычисления над ним.

Этап 1Промежуточный ДМ в H1:M1: {=СЧЁТЕСЛИ(A1:F1;A1:F1)}
Этап 2Итог в O1: =СЧЁТЕСЛИ(H1:M1;2)
ПроверкаПромежуточные значения видны, и ошибку легко найти
ABCDEFGHIJKLMNO
13538512221214

A1:F1 — данные; H1:M1 — сколько раз встречается каждое число; O1 — сколько ячеек содержат числа, которые встречаются ровно дважды (3 и 5 → 4 ячейки).
